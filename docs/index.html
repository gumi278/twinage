ここは何？

ここにあるチャット環境のデモは、ツイネージュの挙動を技術的に検証・体験いただくために作成したのですが、 ドキュメントとして振る舞ってもらうことで説明コストを削減する試みも兼ねることにしました。

それぞれのデモはOpenAI互換のクラウドAPI利用を前提としていますが、git cloneで持ってくればローカルLLMを利用できます。 できますが、簡易版実装のため、トークン消費が激しいです。 少なく見積もっても200Kほどトークンを消費します（当然会話を続けると累積します）。 ローカルLLMで実行する場合は、消耗を見越した context window 設定が必要になります。

応答の質にはLLMの賢さが大きく作用します。 特にデモ版（簡易実装）はノイズが多いため、各社の最新モデルの利用を推奨します。
