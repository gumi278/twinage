Extract Demo について・利用上の注意

本デモは、Obsidian Web Clipper 等で保存された AI との対話 Markdown ファイルから、Twinage の「成分分離工程（Engram Extraction）」を手軽に体験するためのブラウザ実行版です。

  • 発話タグ設定（User / Assistant）について: デフォルト設定の User タグ（**You**）および Assistant タグ（**Gemini**）は、Obsidian Web Clipper で WebUI 版 Gemini との対話ログをファイル化したものを利用する場合を想定しています。ChatGPT（**ChatGPT**）や Claude（**Claude**）など、他の生成AIとの対話ログを利用する場合は、画面上部の設定欄でお使いの Markdown 内の発話タグに合わせて変更してください。
  • 前提フォーマット: Obsidian Web Clipper で保存された Markdown（Frontmatter に created: YYYY-MM-DD を含む形式、および設定した User / Assistant 発話タグ）を前提としています。
  • ファイルサイズ制限: 入力可能な Markdown ファイルは 256KB 以下 です。この上限は、過大サイズのファイル入力によって意図しない大量の LLM API 呼び出しや料金発生（課金事故）が起きるのを防止するために設けている Web デモ固有の安全制限 です。リポジトリ内の Python コード側にはこのような上限制限はありません。
  • セッション番号の固定と重複に関する注意: 本デモではセッション番号（SESSION）を強制的に 01 固定で採番します。そのため、同一日付の Markdown ファイルを複数処理すると生成される 15桁 Opaque ID が競合する可能性があります。
  • ローカルLLMの活用・本番環境の利用について: 本WebデモではクラウドAPI（Gemini）を利用していますが、本リポジトリの Python 実装（src/twinage/extractors/obsidian.py）では、クラウドAPIに加えて Ollama や LM Studio などのローカルLLM（OpenAI 互換エンドポイント）を用いた完全オフラインでの成分分離 も可能です。また、セッション台帳（SESSION-REGISTRY.json）による重複防止や一括バッチ処理など、柔軟な実行が行えます。
